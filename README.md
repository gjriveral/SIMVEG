# SIMVEG

**SIMVEG - Sistema de Simulación y Modelado de Violencias con Énfasis en Género**

Plataforma de simulación y modelado para el análisis de violencias con énfasis en género en el departamento de Antioquia, Colombia. Integra pronóstico estadístico (Prophet) y simulación basada en agentes para auditoría operativa institucional.

## Módulos

- **Pronóstico:** Predicción de casos de violencia a partir de series temporales SIVIGILA.
- **Auditoría Operativa:** Simulador de capacidad institucional, cuellos de botella y triage.

## Ejecución

```bash
pip install -r requirements.txt
streamlit run simveg.py
```

## Datos

Los datos provienen de SIVIGILA (violencias) y referencias DANE para municipios de Antioquia.
